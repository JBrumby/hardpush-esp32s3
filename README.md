translated the hardpush from Carlborg to esp32-s3 
origin is: https://github.com/carlborg/hardpush

This library makes Ableton Push 1 standalone. You can use scales and modes and connect it 
directly to ble ord Appletalk/RTP devices.


- If you need wifi or BLE for your Push 1 use this library
- If you need usb connection to your Computer use my hardpush library for teensy 4.1 

Thanks to Carlborg who developed the original sources.
